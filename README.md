# 📝 To-Do Application

A simple and responsive To-Do Application built using React JS and Vite. This application helps users manage daily tasks efficiently with features like adding, deleting, and completing tasks.

---

## 🚀 Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Responsive user interface
- Fast performance using Vite
- Routing with React Router DOM
- Bootstrap integration

---

## 🛠️ Technologies Used

- React JS
- Vite
- Bootstrap
- React Router DOM
- JavaScript
- CSS

## ⚙️ Installation

### Clone Repository

git clone https://github.com/your-username/To-Do-Application.git

### Move to Project Folder

cd To-Do-Application

### Install Dependencies

npm install

### Install Bootstrap

npm install bootstrap

### Install React Router DOM

npm install react-router-dom

### Run Project

npm run dev
